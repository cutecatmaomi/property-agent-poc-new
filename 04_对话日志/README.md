# 对话回归基准

| 文件 | 性质 | 对照重点 |
|---|---|---|
| `historical_online_success.json` | 2026-11-03 真实在线 Golden Questions 回归，标准题 E001-GQ-010 | 原话、模型工具、规划、语义选择、检索结果、终答 |
| `historical_online_fallback.json` | 同批真实在线回归的同义问法负例，PARA-E001-GQ-025 | 联合选择失败后独立匹配，未命中后的回复与当时未通过判定 |
| `current_success.json` | 当前运行版在隔离本机实际执行，使用模拟账号 | 同一道标准题的 GQ ID，前置判断、实际节点输出、授权原答 |
| `current_human_request.json` | 当前运行版在隔离本机实际执行，使用模拟账号 | 转人工诉求触发确定性 `USER_REQUEST`，不生成工单 |

历史两条记录使用当时的 `ONTOLOGY_PACKAGE_POC` 投影，记录保留 Policy ID、版本、原答和当时判定。历史文件记录的中间输出是运行时保存的结构化计划、匹配、工具和生成摘要。当前两条记录使用 `GOLDEN_QUESTIONS_100`，通过回调采集实际 LangGraph 节点返回值，屏蔽临时会话和票据标识。这两条走确定性路径，模型请求为零。

用当前运行版记录对齐技能行为。旧在线日志可对照真实模型阶段的输入意图、选择结果和输出，尤其用于复现失败。兜底日志中的措辞是历史实测原文，验收以评测口径和当前源码为准。
